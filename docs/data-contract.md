# RINEX 3.04观测资料

头行前60列为值、61到80列为label。SYS / # / OBS TYPES系统在第1列、总数第4到6列，观测码从第8列起每4列一个，头部续行继承同系统。卫星观测行前三列卫星ID，之后每槽14列数值、1列LLI、1列SSI；按系统目录取固定槽，不裁到80列也不以空白分词。若物理行少于完整槽数则截断，不能从下一卫星借字符。指数允许E/D，LLI、SSI空缺与数字分开。

flag0/1/6后计数指卫星记录条数，2/3/4/5为随后特殊记录行数；4中的头更新继承未修改字段，整批合法后产生新目录版本。flag6记录周跳另存，不能当常规测量。历元接收钟差单列留存，不再应用修正。支持纳秒精度，无歧义闰秒以UTC原字段保留；共同轴为自1970-01-01T00:00:00 TAI起纳秒，GPS=TAI-19秒。UTC查冻结表，正闰秒对应新effective之前一秒的额外秒，表前及valid_until之后不转换为已知。

utc-leap源在2016-12-31正闰秒与2017-01-01零时各一历元。头TIME OF FIRST OBS用于时间系统，不强制正文首历元等于其日期，但应报告差异。资料不做轨道计算、定位或物理改正。

## 采集器实现（capture_data.rinex3）

固定列均以0基半开切片按真实字节解释，不做空白分词：

- RINEX VERSION / TYPE：版本 `0:9`，文件类型第21列（切片 `20:21`，须为O），卫星系统第41列（切片 `40:41`，空格或M为混合系统）。
- SYS / # / OBS TYPES：系统 `0:1`，总数 `3:6`（仅每个系统首行给出，续行该列为空并继承pending系统），观测码自第8列起每4列一格。
- TIME OF FIRST OBS 为头部宽字段：年 `2:6`、月 `8:14`、日 `14:20`、时 `20:26`、分 `26:33`、秒 `33:44`，时间系统 `48:51`。
- 正文历元行（`>` 开头）为紧凑字段：年 `2:6`、月 `7:9`、日 `10:12`、时 `13:15`、分 `16:18`、秒 `18:29`、flag `29:32`、记录数 `32:35`、接收机钟偏 `35:50`（F15.12，可全空白）。
- 卫星观测行：卫星ID `0:3`，其后每槽16列＝数值 `0:14` + LLI（第15列）+ SSI（第16列）；字节偏移相对文件第0字节，随每条观测输出，缺测可由目录码集合与实际槽集合之差还原。

解析器只接受 RINEX 3.04 观测（O）文件与 UTF-8 兼容 ASCII 字节。空观测槽、空LLI/SSI为null而非0；数值仅接受严格词法，D与E指数等价，拒绝nan/inf/十六进制等非法字符，秒字段小数超过9位直接报错。flag 2/3/5 的后续行只作事件记录，不计为卫星；flag 4 头更新先在候选目录整批验证（含续行累计与声明总数核对），失败抛错且生效目录保持旧版本，成功才把目录版本号加一；flag 6 周跳单独标记并沿用该时刻系统目录，不混入常规观测。历元内卫星标识须唯一，声明数、物理槽数与目录不符时该历元标记 complete=false 并给出原因，不向下一卫星行借字符。

时间保留原时间系统与原秒字段（含UTC显式60秒闰秒）。共同轴为自1970-01-01T00:00:00 TAI起整数纳秒：GPS 民用纳秒加19秒；UTC 仅按清单内冻结 leap_table 与 leap_valid_until 转换，正闰秒沿用新 effective 之前的旧偏移，表首之前或 valid_until 当日及之后报 unknown_leap（无表时同样标注），不查询本机时区。接收机钟偏单列归档，不再次校正观测值或历元时刻。

采集器支持在完整历元边界 checkpoint/resume：快照保存当前目录版本、各系统观测码元组与下一历元字节偏移；重启恢复后旧头版本不会套用于新历元。
